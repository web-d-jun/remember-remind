# 까마귀

> **까**먹어도 **마**음 놓아, **귀**띔해 줄게

살 물건을 잊지 않고 **끝까지 사게** 만드는 위치 기반 쇼핑 리마인더.

| 문제 | 해결 |
|---|---|
| 1. 시간이 지나 잊어버림 | 살 수 있는 매장 근처(150m)를 지나가면 알림 |
| 2. 매장에 가서도 빠뜨림 | 매장 안에 1분 이상 머무르면 남은 목록을 고정 알림으로 표시하고, 다 안 산 채로 나서면 바로 알림 |

## 기억할 물건 저장

"사야지" 하고 떠오르는 순간은 대개 바쁠 때라(요리 중, 샤워 중, 걷는 중) 3초 안에 저장할 수 있어야 한다.

**타이핑을 최대한 줄인다.**

| 방법 | 누르는 횟수 | 동작 |
|---|---|---|
| **말로** (가장 큰 버튼) | 1번 | 🎤 → "우유랑 계란 사야 돼" → 말이 3초 멈추면 **확인 없이 바로 저장**. 잘못 들었으면 [되돌리기] |
| **자주 사는 물건** | 2번 | 시트를 열면 예전에 기억한 물건이 칩으로 나온다. 누르면 바로 추가 (여러 개 연속 가능) |
| **사진으로** | 2~3번 | 📷 → 찍기 → 바로 "이 물건 이름을 말해 주세요". 말하지 않아도 사진만으로 저장 |
| 글자로 | | ⌨️ → "우유, 계란, 휴지"처럼 쉼표로 여러 개 |

- 한 번 고친 매장 종류는 기억해 두고, 다음에 같은 물건을 추가할 때 그대로 쓴다.
- **고르기만 하면 되게**: 타이핑 대신 후보를 눌러 고른다.
  - 음성 인식 확신이 낮으면(60% 미만) 바로 저장하지 않고 "혹시 이거예요?" 후보와 [다시 말하기]를 보여준다.
  - 사진을 찍으면 제품 포장의 글자를 기기 안에서 읽어(ML Kit, 인터넷 불필요) "사진에서 찾은 이름" 후보를 보여준다. 사전 단어(샴푸 등)가 먼저, 그다음 큰 글자 순. 규칙은 `lib/core/ocr_name_picker.dart`.
  - 잘못 저장된 이름은 물건을 눌러 [다시 말하기]로 고친다.
- **앱 아이콘 길게 누르기**: "말로 기억하기", "사진으로 기억하기" 바로가기.
- iOS 최소 버전은 ML Kit 때문에 15.5.

- 말 나누기 규칙은 `lib/core/item_text_parser.dart` (랑/이랑/하고, 쉼표, "사야 돼"·"사 와" 같은 말끝, "을/를" 처리). 띄어쓰기로만 나열하면 모두 아는 물건일 때만 나눈다("종량제 봉투"는 하나로 둔다).
- 음성 인식은 휴대폰 기본 엔진(Android: Google, iOS: Apple)을 쓴다. iOS에는 사전의 물건 이름을 힌트로 준다.
- 사진은 앱 폴더(`photos/`)에 파일 이름으로 저장한다. iOS는 앱 업데이트 때 절대 경로가 바뀌기 때문.

## 알림

사용자는 앱을 거의 열지 않고 알림으로 앱을 만나므로, 알림만으로 끝낼 수 있게 한다.

| 상황 | 알림 | 버튼 |
|---|---|---|
| 매장 근처를 지날 때 | 까악! GS25 시청점 앞이에요 / 여기서 우유를 살 수 있어요 | [샀어요] [오늘은 그만] |
| 매장 안에 머무를 때 | GS25 시청점에서 살 것 2개 (고정 알림, 체크하면 줄어듦) | [다 샀어요] |
| 안 사고 나설 때 | 까먹지 마, 귀가 전에! / GS25 시청점에서 건전지를 안 샀어요 | [샀어요] |

- 알림은 물건마다가 아니라 매장마다 하나. 그 매장에서 살 수 있는 물건만 모아서 보여준다.
- **[샀어요]**는 물건이 하나일 때만 붙는다. 버튼 한 번이 알림의 물건 전부에 적용되므로, 여러 개일 때
  일부만 산 걸 전부 산 걸로 처리하지 않도록 앱이나 매장 안 목록에서 하나씩 체크한다.
- **[오늘은 그만]**: 그 물건은 자정까지 "근처예요" 알림만 쉰다. 매장에 들어가면 목록과 "안 사고 나감" 알림은 그대로 온다.
- 앱이 꺼져 있어도 버튼이 동작한다. 별도 isolate에서 처리하고, 앱이 떠 있으면 `IsolateNameServer`로 넘겨 화면에 바로 반영한다.
- 문구는 `lib/core/notification_copy.dart`에 모아 두었다.

## 실행

```bash
flutter run
```

API 키나 네트워크가 필요 없습니다. 주변 매장 데이터는 앱에 내장되어 있습니다.

    notification_service.dart

### 근접 판단 기준 (`ProximityConfig`)

- 접근 알림: 150m 이내, 시속 약 25km 이하(차량 이동 제외), 같은 매장 3시간 / 같은 종류 30분 쿨다운
- 접근 알림은 한 번에 한 매장. 가장 가까운 매장이 이미 알렸으면 그다음 가까운 매장(살 물건이 다른 곳)을 알린다.
- 매장 안: 40m 이내에서 60초 이상 머무름. 그동안 처음 위치에서 40m 넘게 움직이면 지나가는 중으로 보고 다시 센다
  (이게 없으면 보통 걸음으로 앞을 지나가기만 해도 "안 사고 나갔다" 알림이 온다)
- 매장 이탈: 80m 밖으로 벗어남 (40m와 차이를 둬서 GPS 흔들림 방지)
- **대형 매장** (대규모점포 데이터, 또는 "큰 매장"으로 직접 등록한 곳): 매장 안에서는 GPS가
  매장 좌표에서 100m 넘게 어긋나므로 따로 판단한다.
  - 매장 안: 150m 이내에서 5분 이상 머무름. 그동안 처음 위치에서 150m 넘게 움직이면 다시 센다.
    매장 좌표 가까이 와도 일반 매장 기준(60초)은 쓰지 않는다.
  - 대형 매장 방문과 일반 매장 방문은 따로 센다. 서울역처럼 가게가 많은 건물 안에서 마트를 돌다
    다른 가게 좌표 40m 안을 지나가도 마트 타이머가 끊기지 않는다. 한쪽이 확정되면 다른 쪽은 버린다.
  - **입점 매장**: 대형 매장 좌표 30m 안의 다른 매장(이마트 안 약국·올리브영 등)은 대형 매장에 묶는다.
    좌표를 주소로 찍어서 입점 매장은 거의 같은 점에 있다(대형마트 445곳 중 약국 132곳이 10m, 52곳이 30m 안).
    근처 알림은 한 번("여기서 쌀, 감기약을 살 수 있어요 (안에 약국이 있어요)"), 매장 안 목록에는
    "• 감기약 (약국)"처럼 어디서 사는지 붙이고, 떠날 때는 묶음 전체에서 안 산 물건을 알린다.
  - 매장 이탈: 250m 밖으로 벗어남
  - 근처에 머무는 동안(확정 전)에는 지나가는 다른 매장 알림을 막지 않는다.

## 내 매장 (직접 등록)

내장 데이터에 없는 매장(다이소 대부분, 새로 생긴 매장)은 홈 화면 오른쪽 위 🏪 → **지금 있는 곳 등록**으로
추가한다. 매장 종류만 고르면 이름은 자동으로 채워지고, 마트·다이소는 "큰 매장"이 기본으로 켜진다.
기기 안(shared_preferences)에만 저장한다. 나중에 수익이 생기면 카카오 로컬 API 실시간 검색을 붙일 수 있다
(결과는 저장하지 않는 조건).

## iOS 백그라운드

위치 스트림은 앱이 살아 있는 동안만 동작한다. iOS가 앱을 종료한 뒤에도 다시 깨어나도록:

- **주요 위치 변경**(약 500m 이동)과 **지역 모니터링**(최대 20개 원)을 켠다. 지역은 살 물건이 있는
  가까운 매장 19곳(150m) + 지금 있는 곳(300m, 나서면 깨어남).
- 깨어나면 화면이 없으므로(UIScene 구조) `AppDelegate`가 화면 없는 Flutter 엔진으로 `backgroundMain`
  을 실행해 위치 스트림을 다시 시작한다. 사용자가 앱을 열면 그 엔진은 끈다.
- 살 물건이 없으면 모두 끈다.

**주의**: 사용자가 앱 전환기에서 **직접 쓸어 올려 종료**한 경우에 다시 깨워 주는지는 iOS 버전마다 다르게
보고된다(iOS 26에서 안 깨운다는 보고가 있다). 메모리 부족 등으로 시스템이 종료한 경우는 깨운다.
실기기에서 꼭 확인할 것.

### 확실한 매장과 불확실한 매장

슈퍼마켓 업종에는 주유소·수예점·솜사탕 가게 등이 섞여 있어(약 절반은 이름에 식료품 가게라는 단서가 없음),
"달콤한솜사탕에서 젖병솔을 살 수 있어요" 같은 엉뚱한 알림이 갔다. 부정확한 데이터를 정확한 것처럼 말하지 않도록
매장을 나눈다 (`is_certain`, 데이터 다섯째 칸 `U`).

| | 매장 | 알림 |
|---|---|---|
| 확실 | 대형마트·브랜드 마트(하나로·GS더프레시·노브랜드 등)·이름에 "슈퍼"·체인 편의점·약국·다이소·올리브영·문구점·과자 할인점·내 매장 | "까악! GS25 앞이에요 / 여기서 우유를 살 수 있어요", 매장 안·안 사고 나감 알림 |
| 불확실 | 그 밖의 동네 마트·상회(약 4만 3천 곳), 체인이 아닌 편의점(약 4천 곳) | "까악! 혹시 이 근처에…? / 우유를 파는 가게가 있을지도 몰라요 · 행복상회 외 2곳 (확실하진 않아요)" — 소리 없이, 2시간에 한 번. 근처 확실한 매장에서 살 수 있는 물건은 뺀다. 매장 안·안 사고 나감 알림은 보내지 않는다 |
| 제외 | 주유소·페인트·철물·전기·설비·간판·인쇄·캠프장·식당 등 식료품을 안 파는 게 분명한 이름 (약 1,600곳). 이름에 "슈퍼"·"마트" 같은 근거가 있으면 남긴다("경남슈퍼철물") | 없음 |

홈 화면에는 "근처에서 살 수 있는 곳"과 "혹시 있을지도 몰라요 (확실하진 않아요)"를 나눠 보여준다.
솜사탕·사탕 가게는 아이스크림·과자 할인점으로, 슈퍼마켓 업종으로 잘못 등록된 GS25·CU는 편의점으로 옮긴다.
이미 만든 데이터에 규칙만 다시 적용: `python tool/build_store_data.py --refilter`

**갱신 방법**: 위 페이지에서 zip을 받은 뒤

```bash
python tool/build_store_data.py <받은 zip 경로>
```

### 대형마트 보완

소상공인 데이터에는 이마트·홈플러스·롯데마트·코스트코 같은 대형마트가 거의 빠져 있어서,
[행정안전부 생활_대규모점포 조회서비스](https://www.data.go.kr/data/15154948/openapi.do)
(매일 갱신, 이용허락범위 제한 없음)로 채웁니다. 영업 중인 대형마트를 골라 좌표를 EPSG:5174에서
WGS84로 바꾸고, 같은 자리에 있는 기존 항목(매장 안 입점 업체 등)은 교체합니다.

```bash
python tool/fetch_large_stores.py <공공데이터포털 서비스키>
```

- 2026-11 기준 전체 4,198건 → 대형마트 등 642곳 (대형 445곳, 홈플러스 익스프레스 같은 작은 매장 197곳).
  같은 매장이 여러 번 등록된 경우(재등록, 회사명 변경)는 하나로 합치고, 이름의 `(주)`·회사명은 뗍니다.
  작은 매장에는 대형 매장 판정(L)을 붙이지 않습니다.
- 결과는 `tool/large_stores.tsv`에 남습니다. 커밋해 두면 `build_store_data.py`로 다시 만들 때 서비스키 없이 자동으로 합쳐집니다.
- 카카오 로컬 API 결과는 저장·재배포가 금지되어 있어 내장 데이터에 쓰지 않습니다.

## 알려진 한계 (MVP)

- 다이소는 소상공인 데이터에 거의 없어서, 사용자가 직접 등록해야 합니다.
- 매장 등록은 "지금 있는 곳"만 됩니다. (지도에서 고르기 없음)
- 데이터가 분기마다 갱신되므로 새로 생긴 매장은 다음 갱신 때까지 빠집니다.
