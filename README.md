# 빠짐없이

살 물건을 잊지 않고 **끝까지 사게** 만드는 위치 기반 쇼핑 리마인더.

| 문제 | 해결 |
|---|---|
| 1. 시간이 지나 잊어버림 | 살 수 있는 매장 근처(150m)를 지나가면 알림 |
| 2. 매장에 가서도 빠뜨림 | 매장 안에 1분 이상 머무르면 남은 목록을 고정 알림으로 표시하고, 다 안 산 채로 나서면 바로 알림 |

## 실행

```bash
flutter run
```

API 키나 네트워크가 필요 없습니다. 주변 매장 데이터는 앱에 내장되어 있습니다.

## 구조

```
lib/
  core/
    proximity_engine.dart   접근/체류/이탈 판단 (순수 Dart, 핵심 로직)
    item_categorizer.dart   물건 이름 → 매장 종류 추천 (키워드 사전)
    geo.dart                좌표, 거리 계산
  data/
    place_source.dart       내장 데이터에서 주변 매장 검색 (첫 검색 때 isolate에서 로드)
    store_index.dart        전국 매장 격자 인덱스 (약 1km 칸)
    store_cache.dart        500m 이상 이동했을 때만 매장 재조회
    item_repository.dart    기기 내 저장 (shared_preferences)
  services/
    location_tracker.dart   위치 스트림 → 엔진 → 알림 연결
    notification_service.dart
  state/shopping_list.dart
  ui/
```

### 근접 판단 기준 (`ProximityConfig`)

- 접근 알림: 150m 이내, 시속 약 25km 이하(차량 이동 제외), 같은 매장 3시간 / 같은 종류 30분 쿨다운
- 매장 안: 40m 이내에서 60초 이상 머무름
- 매장 이탈: 80m 밖으로 벗어남 (40m와 차이를 둬서 GPS 흔들림 방지)

## 매장 데이터

[소상공인시장진흥공단 상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)
(분기별 갱신, 이용허락범위 제한 없음)에서 필요한 업종만 골라 `assets/stores.tsv.gz`(약 2.4MB, 16만 곳)로 만듭니다.

| 앱 분류 | 기준 | 전국 개수 (2026-09 기준) |
|---|---|---|
| 마트·슈퍼 | 업종 G20404 슈퍼마켓 | 약 66,000 |
| 편의점 | 업종 G20405 편의점 | 약 57,500 |
| 약국 | 업종 G21501 약국 | 약 25,000 |
| 문구점 | 업종 G21302 문구/회화용품 | 약 8,900 |
| 올리브영 | 상호명에 "올리브영" | 약 1,600 |
| 다이소 | 상호명에 "다이소" | 약 400 (실제보다 많이 적음) |

**갱신 방법**: 위 페이지에서 zip을 받은 뒤

```bash
python tool/build_store_data.py <받은 zip 경로>
```

## 알려진 한계 (MVP)

- 다이소, 대형마트(이마트·홈플러스 본점 등)는 소상공인 데이터에 거의 없습니다. 사용자가 매장을 직접
  등록하는 기능으로 보완할 예정입니다.
- 데이터가 분기마다 갱신되므로 새로 생긴 매장은 다음 갱신 때까지 빠집니다.

- 앱 프로세스가 살아 있는 동안 위치 스트림으로 동작합니다. Android는 포그라운드 서비스로 유지되지만,
  iOS에서 사용자가 앱을 완전히 종료하면 추적이 멈춥니다. 다음 단계로 iOS 지역 모니터링/Significant
  Location Change를 붙여야 합니다.
- 실내 GPS 오차 때문에 대형 마트에서는 체류 판정이 늦어질 수 있습니다.
- 알림에서 바로 "샀어요" 체크하는 액션은 아직 없습니다.
